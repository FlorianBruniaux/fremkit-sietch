# Changelog

## 1.0.0

- Add selected Chrome YouTube video reception, pairing guidance and exact-session playback controls. Requires the companion extension and local bridge; no second YouTube player is created.

- Restore the video after a temporary connection loss, control the visible Short, and ignore failures from an old capture.
- Keep a replacement screen share active when an older connection fails, and target the centered Shorts video when Chrome marks none active.

# Changelog

What changed for the person using this widget, version by version. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); the newest version is first, and the
entry of the version being published is what the Fremkit admin shows before an update.

## 1.2.4

### Added
- Filter loaded notifications and reviews by GitHub owner and repository. Mark-read affects matching notifications when filtered.

## 1.2.3

### Added
- Show GitHub, notification and pull-request icons with a clearer unread count. Capped review counts carry a plus sign.

## 1.2.2

### Changed
- Increase touch targets to 56 pixels and improve text hierarchy without changing click actions or compact mode.

## 1.2.1

### Fixed
- Confirm when notifications are marked read. Restore unread rows and show an error when GitHub refuses the request.

## 1.2.0

### Fixed
- Open the selected notification, review request or pull request in the Mac browser without marking it read.

## 1.1.1 — 2026-09-18

### Changed
- Reads the theme's colours, fonts and text scale.

## 1.1.0 — 2026-09-18

### Added
- First release on the registry. What is waiting on GitHub: review requests, assigned issues
  and notifications, with a touch to open one.
